## proyecto de video analyser

se introduce una url directa a un video
el sistema enseña los detalles del video
se puede descargar el video
hay un historial con fecha de las busquedas singulas
se pueden borrar las busquedas
hay un botón para cambiar el modo claro y oscuro
hay elementos que se adaptan al contenido o cambian segun la acción
